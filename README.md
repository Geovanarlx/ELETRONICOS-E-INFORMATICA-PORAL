# Nexora — portal institucional

Protótipo responsivo de uma empresa fictícia de tecnologia e eletrônicos, desenvolvido em português com HTML semântico, Tailwind CSS 4, CSS de identidade visual e JavaScript.

## Abrir

Abra `index.html` em um navegador com conexão à internet. O protótipo usa o Play CDN oficial do Tailwind v4 e Google Fonts; os produtos são demonstrativos e as fotografias reais são carregadas do Unsplash. O Play CDN é indicado para desenvolvimento e prototipação, não para produção.

## Link de Acesso 
https://geovanarlx.github.io/ELETRONICOS-E-INFORMATICA-PORAL/

## Marca

O sistema de identidade, a logo original em SVG, a paleta, tipografia, voz e direção visual estão documentados em [`BRAND.md`](BRAND.md).

## Escopo da interface

- Portal responsivo com menu mobile, tema claro/escuro persistente e navegação por seções.
- Catálogo demonstrativo de quatro produtos com fotos reais, preço, favorito e feedback de seleção.
- Áreas institucionais para serviços, missão, contato e newsletter.
- Estrutura pronta para evolução de conteúdo: substituir dados e textos demonstrativos por CMS e conectar os formulários a serviços reais.

## Imagens

As fotografias são referências visuais remotas hospedadas no Unsplash. Textos, nome comercial, símbolo, paleta e composição do site foram criados para este protótipo; a interface usa padrões amplos de descoberta de produtos comuns ao comércio eletrônico.
